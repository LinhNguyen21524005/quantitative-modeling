# Quantitative Modeling & Econometrics Portfolio

A collection of applied econometric and statistical modeling implementations using Stata, developed through graduate-level coursework in Global Finance and Economics.

## Areas of Quantitative Modeling

**1. Multiple Linear Regression**
- OLS estimation and model specification
- Variable selection and hypothesis testing
- Model comparison and regression diagnostics

**2. Limited Dependent Variable Models**
- Binary choice models: Logit and Probit
- Tobit regression
- Poisson and Negative Binomial models
- Heckman sample selection models
- Marginal effects and predictive probabilities

**3. Panel Data Econometrics**
- Fixed Effects and Random Effects
- Panel data estimation
- Longitudinal economic data analysis

**4. Machine Learning**
- Ridge Regression
- LASSO
- Elastic Net
- Training-sample prediction and model comparison
- Information-criterion-based model selection

## Tools & Technologies
- Stata
- Econometrics
- Statistical Modeling
- Predictive Analytics
- Machine Learning

## Academic Background
MSc in Global Finance and Economics

## Repository Purpose
This repository documents practical implementations of econometric and statistical models and demonstrates quantitative programming skills applied to economic and financial datasets.

*Note: These scripts are primarily academic exercises and applied coursework implementations, rather than independent production-grade modeling systems.*
